# Индикаторы для TradingView

Два индикатора на Pine Script v5 для внутридневной торговли на форексе.
Без обещаний доходности: инструменты показывают данные, решение принимает трейдер.

---

## RVOL — относительный объём

`rvol.pine`

Показывает, во сколько раз объём текущего бара превышает средний за выбранный период.
Помогает отличить движение, за которым стоят участники, от пустого шума.

### Как читать

| Значение | Что означает |
|---|---|
| ниже 1.0 | объём ниже среднего, движение неубедительное |
| 1.0 – 2.0 | норма |
| выше 2.0 | повышенный интерес |
| выше 3.0 | резкая аномалия: новость или крупный игрок |

### Настройки

| Параметр | По умолчанию | Назначение |
|---|---|---|
| Period | 20 | период среднего объёма |
| Threshold | 2.0 | порог аномалии |
| Session only | вкл | фильтр торговой сессии |
| Session | 1000-1900 | торговые часы |
| Timezone | Europe/Moscow | часовой пояс сессии |

При превышении порога столбик становится оранжевым, фон графика подсвечивается.
Есть алерт на пересечение порога.

### Зачем фильтр сессии

На форексе ночной объём низкий: всплески в азиатскую сессию дают ложные сигналы.
Фильтр отключает построение вне выбранных часов.

## ATR Risk Manager

`atr-risk-manager.pine`

Считает размер позиции от волатильности и риска. Рисует уровни стопа на графике
и выводит таблицу с расчётом.

### Формулы

```
Стоп, пунктов = clamp(ATR / размер пункта * множитель, минимум, максимум)
Риск, деньги  = депозит * риск%
Лот           = риск / (стоп в пунктах * стоимость пункта)
Тейк 2R       = стоп * 2
```

### Настройки

| Параметр | По умолчанию | Назначение |
|---|---|---|
| ATR length | 14 | период ATR |
| ATR multiplier | 2.0 | множитель стопа |
| Min stop, pips | 5 | минимальный стоп |
| Max stop, pips | 12 | максимальный стоп |
| Deposit | 100000 | размер депозита |
| Risk per trade, % | 1.0 | риск на сделку |
| Pip value per 1 lot | 830 | стоимость пункта на лот, ₽ |
| Pip size | 0.0001 | размер пункта |

### Что показывает таблица

- **ATR** — текущая волатильность в пунктах;
- **Stop** — рассчитанный стоп;
- **Lot** — размер позиции;
- **Risk** — риск в деньгах;
- **Target 2R** — цель при соотношении 1:2.

## Установка

1. Открыть график в TradingView.
2. Внизу нажать **Pine Editor**.
3. Удалить код-заглушку.
4. Вставить содержимое `.pine` файла.
5. **Сохранить** → **Добавить на график**.

Копировать код лучше из текстового редактора (Блокнот, VS Code), а не из браузера:
при копировании из веб-страниц иногда приезжают невидимые символы и «умные» кавычки,
из-за которых парсер выдаёт ошибку.

## Ограничения

- На форексе используется **тиковый объём** — число изменений цены, а не объём реальных
  сделок. Рынок децентрализован, единого объёма не существует, поэтому абсолютные
  значения имеют смысл только относительно среднего.
- Индикаторы **не дают сигналов** на покупку или продажу и не прогнозируют направление.
- Расчёт лота в ATR Risk Manager — ориентировочный: фактическая стоимость пункта зависит
  от брокера, валюты счёта и текущего курса.
